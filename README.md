# 3Maigo Bot V1.0
Prototype of the 3Maigo Telegram economy.

Features:
- User registration
- Internal 3M balance
- Daily reward
- Engagement mining
- Referral codes
- Tasks
- Transaction ledger
- Basic admin API
- Revenue/Treasury placeholders

Important: this V1 uses an internal ledger only. It does NOT create or promise a blockchain token.
